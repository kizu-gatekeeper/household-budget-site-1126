**HomeLedger** — a household budget planner that runs entirely in the browser: an interactive monthly budget table across 15 categories (needs / wants / savings) with live totals and a 50/30/20 split analyser with verdicts, four complete loadable budget templates (family of four, city couple, first job, tight month), a savings-goal calculator with interest, a bill calendar, and plain-language guides & FAQ. Budgets persist in local storage; no account, no uploads. Plain static files under `app/` — no build step, no network requests.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts && node serve.ts
```
